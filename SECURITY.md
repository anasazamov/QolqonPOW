# Security

QalqonPoW is an **unaudited research prototype**. No chain runs it, so there is nothing
live to exploit, and public disclosure in an issue is fine for design flaws.

If you find something that could affect a project that has adopted the code, report it
privately through GitHub's "Report a vulnerability" (Security → Advisories) on this repository.

Known limitations are listed under "Open problems" in the [README](README.md).
